## 主な変更

- 図鑑 / ホーム / 庭園 / 手入れ。初期画面は固定された中央庭園。
- SwiftUI + SpriteKitの庭、仮人型、最大15植物、限定カメラ、鑑賞専用入力、観察から同一画面で編集。
- 咲かせる / 演習 / 正式復習を分離。演習は開花も復習期限も進めない。
- 手入れは1属1形式。最大5属の開始前プレビュー、近日の予定、自由復習。
- 正本の段階制復習、惜しい/不正解/早期ボーナス、属単位24時間再学習ロック、期限超過からだけ退色。
- 図鑑を開くだけでは再学習扱いにしない。保護中は「幽香に訊く」で明示的に確認。
- 専用カタカナ/英字入力。予測候補なし、Returnは送信しない。
- 307属原文・過去の成績・写真・履歴を保持。schema 1/2→3、移行前原本保存、写真込みバックアップ。
- 庭への所属と表示を分離し、枠が埋まっても控えとして保持。解放は安全な節目のみ。
- 任意通知、減らすアニメーション、触覚、バージョンと元コミット表示。

## ビルド

Windowsで編集し、既存GitHub Actions（macos-15 / XcodeGen）でテストとunsigned IPAを生成します。iOS17以上。外部Swiftパッケージなし。
`.github/workflows/ios.yml` は変更不要です。main/masterへのpushと手動実行に対応しています。

Bundle ID `io.github.nezumihi12.hanazukan`、保存先 Application Support/Hanazukan、Photos参照を保持します。内部名はSideStore対策でASCII、日本語のアイコン下表示はja.lprojで指定します（実機検証項目）。

最終人物アート・正式台詞・植物の仕上げ・音源は未収録または仮素材です。全Acceptance Criteria合格済みという意味ではありません。残作業と確認項目は実装報告を参照してください。
