# Core v0の由来

ユーザー提供の共有会話 https://chatgpt.com/share/6abcd6ba-645c-83e8-a814-7393779b15b4 のSVG生成コードから復元。
54パーツ（骨格12、葉14、花18、花序10）。元SVGをCoreV0に保存し、iOS用の通常状態PNGをAssets.xcassetsへ変換した。
退色状態の画像は作成しない。SwiftUIの彩度・色の乗算・透明度で表す。

属別の記述も同じ共有会話の科別既定値と属別上書きから抽出した。元の設計案にはCore v0より多い分類があるため、12/14/18/10の部品への対応は近似。render-plan.jsonに元記述と対応部品を保存した。
属固有アクセントは汎用の果実・つる・葉脈のみで、最終的な属の同定用画像ではない。花なしのシダ等も「開花」は学習実績名であり、生物学的な花を追加しない。
SVG再生成: python scripts/rebuild_core_v0.py。変換済みPNGを同梱するので通常ビルドに変換環境は不要。
