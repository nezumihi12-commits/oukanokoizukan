# v1 更新手順

1. 現在のアプリで、記録 → 写真を含むバックアップを作成し、端末外にも保存します。
2. oukanokoizukan-v1-update.zip をWindowsで展開します。
3. GitHubの oukanokoizukan で **App / Tests / project.yml が並ぶ階層**を開き、Add file → Upload files。
4. 展開された **App / Art / Tests / scripts / docs / README.md / project.yml** をまとめて投入します。ZIP自体や外側のフォルダを投入しません。既存の同じパスは上書き、新規は追加。全削除は不要です。
5. mainにコミットすると、既存の Build and test iOS が起動します。「Add files via upload」はコミット名で、ファイル更新専用のActionという意味ではありません。
6. **今回のコミットの緑の実行**から Hanazukan-unsigned-IPA をダウンロード。展開したIPAを取り出します。
7. SideStoreの＋で新しいIPAを指定します。Refreshは署名更新なので、新版の差し替えにはなりません。履歴を保持するため、既存アプリは削除しません。
8. 手入れ → 設定で **v1.0 / ビルド番号 / ソースコミット**を確認します。タブは「図鑑 / ホーム / 庭園 / 手入れ」です。

既存workflowは変更していません。隠しフォルダ .github を移し直す必要はありません。
完全版ZIPは保管・新しいチェックアウト用です。既存リポジトリには update.zip を使うと二重フォルダを避けられます。

## まとめて実機確認

- 旧開花数、総合成績、セッション履歴、写真、位置、お気に入りが残る。
- 演習で未開花属を3形式正解しても開花せず、「咲かせる」で進む。
- 図鑑を開くだけでは予定や色が回復しない。
- 保護中の「幽香に訊く」で、おまかせ対象から24時間外れる。
- 固定ホームに縦スクロールなし。全画面鑑賞ではタップで退出UIだけ表示。
- 編集を破棄すると元の配置、完了後は再起動しても保持。控え植栽も残る。
- 設定 → 描画の実機検証で、15植物＋仮人型のFPSとカメラを確認。
- カタカナ/英字入力に予測候補なし。最後のReturnで閉じ、回答はボタンで確定。
- 通知は任意ON、手入れ完了後に取消。日本語表示名でSideStoreの署名エラーが再発しない。

今回のAppleビルドはまだ実行していません。Actionsが失敗した場合は実行URLと最初のerror行が次の確認対象です。テスト失敗時にはIPAを作りません。
