## 参照した実体

添付`index (1).html`を読み取り、公開リポジトリHEAD `b14aab4a8433e665113826cc4a375ad4ebb3286f`の`index.html`と比較。改行を除いて一致。添付を正本とし、GENERAリテラルの全307件と`getJpInfo`の結果を抽出した。6項目はlatin / read / family / oldFamily / jpName / note。配列順・文字列は変更していない。

過去会話や画面には300属とあるが、実際は307属。元の範囲入力は300でクランプされ、末尾7属を番号で選べないため、ネイティブ版では実件数で上限を設定した。

## 状態の対応

| Web版 | ネイティブ版 | 挙動 |
|---|---|---|
| unlocked | AppState.unlocked | 写真登録で発見済み。写真を全削除しても発見済みは維持 |
| accuracy[latin][mode] | records[latin].accuracy[mode] | correct / total。完全正解のみcorrectを加算 |
| mastery | StudyRecord.mastery | 基本3形式の試行済み形式の平均。0.3/0.6/0.8境界で0/1/2/3 |
| countMemorized | StudyRecord.memorized | latin2family・jp2latin・latin2jpそれぞれでcorrect > 0 |
| weak | StudyRecord.weak | 同じ平均が0.5未満。未出題は除外 |
| todayCount / todayDate | dailyCounts[端末のローカル日付] | 出題表示時ではなく回答確定時に加算 |
| history | sessions | 完了・途中終了を保存。旧版の最大20件制限を廃止 |
| photoCache / IndexedDB | photos / Photosファイル | 配列が空でない属を写真ありと判定 |
| location[latin] | locations[latin] | その属の代表観察位置。写真ごとの位置も別途保存 |
| lastRange | rangeFrom / rangeTo | 再起動後も保持 |

基本3形式の平均は「正解合計÷問題数合計」ではない。例えば8/10と0/1なら40%で苦手。全体の形式別正答率は、その形式のcorrect・totalを全属で合算する。

## 出題・採点

- 基本の20問は重複しない属からランダム選択。写真問題は写真がある属のみ。混合は基本3形式からランダム選択し、科名列挙を含めない。
- 科名列挙は選ばれた属の科を問い、回答対象は範囲内だけでなく**全収録データの同じ科**。同じ科の問題がセッションに複数出ることは元仕様どおりあり得る。成績の記録先は種になる属IDとfamily2genusモードで、基本3形式の習熟度には含めない。
- ラテン語はtrim・小文字化して一致で1点、Levenshtein距離1で0.5点。和名は「属」、科名は「科」を除いて照合。旧科名の括弧等は元文字列どおり扱い、勝手な別名展開はしない。
- 和名候補は元`getJpInfo`関数の出力を事前計算。備考の最初の句から代表種名を抽出する除外条件も元結果を保持。
- 写真問題は属名・科名の2欄を平均し、1問1点。完全正解には両方の満点が必要。回答フィードバックには正答と備考を表示。

## 意図的に修正した挙動

1. 初期selectedModeが未定義モード`latin2all`だった不整合を`latin2family`に統一。
2. 図鑑の写真フィルターが常にfalseを返す不具合を修正。
3. 該当する苦手がない場合など、黙って全属に切り替えず、対象なしと表示。
4. 科名列挙では同じ入力トークンを複数の属に再利用しない。元版はスペル部分点のみでも全体正解になり得たが、完全一致の満点のみ正答率に加算。
5. 日付が変わった後も起動し直さず回答数を新しい日に加算。表示は30秒ごとに更新。
6. 部分点をセッション得点に反映し、途中終了も履歴に保存。OSによる強制終了では回答成績は残るが進行中セッションの再開・履歴生成はしない。
7. 元のunlocked（写真で発見済み）とmemorized（3形式正解）を別のフィルター名で表示。
8. 写真GPSの0度も有効値として扱い、南緯・西経を反映。GPS欠落時は位置を推測しない。

## 写真と位置の制約

写真選択はPhotosPicker。ライブラリ全件の権限を要求せず、選択された画像データを読み込む。クラウド上の写真は取得に通信が必要になる場合がある。EXIFがPhotosPickerの受け渡しに含まれない場合、撮影日時・位置は取得できない。日時にはタイムゾーンがない場合があり、端末のローカル時間として解釈する。

オリジナル画像から情報を読んだ後、画像自体は最大1800pxのJPEGへ変換しGPSを埋め込まない。撮影日時・GPSを保存しない設定も選べる。属の観察位置は最新登録のGPSまたは手動現在地で更新する。写真削除だけでは属の観察位置は削除しない。位置削除操作は属の位置と、その属の全登録写真のGPSを削除する。

MapKit地図はオンライン時に地図タイルを取得するため、完全オフラインで背景地図が表示される保証はない。図鑑・クイズ・登録済み写真・成績はネット接続なしで使える。

## 拡張の境界

- `StateRepository`に永続化を分離。`schemaVersion`で将来の移行を明示。現時点ではv1以外を拒否。
- `SyncService` / `LocalOnlySync`は未接続の差し替え口。Firebase認証、競合解決、削除同期、Cloudinary転送は別途実装が必要。APIキー・既存Web版のクラウド設定はコピーしない。
- `StudySnapshot` / `SnapshotPublishing`はWidget共有データの土台。App Groupコンテナ・WidgetKit拡張は未追加。
- `StudyActionHandling` / `StudyRouter`はApp Intentsの接続口。アプリ画面との配線・Intent宣言・Shortcuts登録は未追加。
- `LocalReminderService`は許可要求・毎日指定時刻の通知登録・取り消しを持つが、設定画面からは呼ばない。
- `GardenState` / `CharacterState` / `EventCondition` / `GardenEvents`を用意。得点報酬、植物アンロック、ゲーム演出、キャラクター台詞は勝手に確定しない。庭画面は静的プレースホルダーと学習数表示のみ。
