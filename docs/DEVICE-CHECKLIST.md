# v0.3 一括実機確認

1. 更新前に記録タブから写真込みバックアップを保存。アプリを削除せず、同じBundle IDのIPAを上書きする。
2. 旧写真・履歴・正答率・開花日を確認。ホームで7区画が表示されること。
3. 開花学習で1属を3形式正解。芽→成長→開花、行き先3択を確認。
4. 英字の専用QWERTY、日本語の上下左右フリック、濁点・半濁点・小文字・削除を確認。
5. 科名は「科」なし、和名はひらがなでも正解。列挙は前へ/次へで複数欄を移動。
6. 即答5秒で時間切れ。通常/復習では時間切れにならないこと。
7. 図鑑の隠すメニューで4項目を切替。科名だけをめくってから復習し、24時間以内の段階進行が抑制されること。
8. 庭の区画→観察→編集。長押しで移動、トレイへ戻す、完了で保存、戻るで破棄確認、10秒以内のUndo。
9. 水生植物が乾いたスポットへ入らないこと、既存植物を無断で追い出さないこと。
10. 中央庭園満杯時の入れ替え・編集・委任待ち。未配置と育苗が別一覧であること。
11. おまかせ復習最大5属、自由復習は5属を超えて選択できること。復習の正答は3形式回答後にまとめて表示。
12. 再起動後の配置・お気に入り・未配置・委任待ちが保存されること。
13. 10属以降の区画解放と8属間隔、手動配置が自動移植されないこと。
14. 数日後に色彩低下・曖昧の庭の永久解放を確認。端末時刻変更は推奨しない。境界値はXCTestで検証する。

# 一回の導入でまとめて確認

v0.2の庭・復習・旧データ移行の確認は [V02-GARDEN.md](V02-GARDEN.md) の実機チェックを併用してください。以下は既存機能の回帰確認です。

未実施の実機確認用チェックリスト。最初はテスト用の写真と記録で試してください。

## 起動・図鑑

- [ ] 初回起動で307属。アカウント登録なしで検索できる。
- [ ] Abelia / アベリア / スイカズラ / 和名・旧科名で検索できる。
- [ ] 最後のZinniaまで表示。307番を範囲指定できる。
- [ ] 詳細の科名・旧科名・備考を元HTMLと照合する。
- [ ] 大きな文字設定・ダークモード・横画面でも回答ボタンが操作できる。

## 学習（各1問にすると短時間）

- [ ] 属名→科名で正答。Acerならムクロジ／ムクロジ科／カエデ科が正解。
- [ ] 和名→ラテン語で大文字小文字無視、1文字ミスで部分点、空欄は不正解。
- [ ] 属名→和名で和名・元データの代表種候補を認める。
- [ ] 科名列挙で全収録の同科が対象。一つの入力で複数属を正解にしない。
- [ ] 混合が基本3形式から出題される。
- [ ] 20問で属が重複せず、結果と履歴が残る。対象が5属なら5問で終わる。
- [ ] 途中終了でも回答済み成績・履歴が残る。終了キャンセルで続行できる。
- [ ] 苦手がない状態で苦手練習を押すと対象なし。勝手に全体へ切り替わらない。
- [ ] 同じ属の基本3形式で正解すると記憶済みが増える。

## 保存

- [ ] 回答後にアプリを終了・再起動して成績が残る。
- [ ] セッション途中で強制終了しても回答済みの正答率は残る（途中セッション再開は非対応）。
- [ ] 指定範囲が再起動後に残る。
- [ ] 日付を跨いだ後、新しい回答が新しい日へ記録される。

## 写真と場所

- [ ] 写真を複数選択して登録・拡大。写真ありフィルターに現れる。
- [ ] 写真問題で属名・科名の両方を採点。写真表示に名前の漏れがない。
- [ ] GPSあり／なしの写真で位置の有無が正しい。南緯・西経も確認。
- [ ] 「撮影日時・位置情報も保存」をオフにして新規登録し、メタデータが保存されない。
- [ ] 現在地記録で許可ダイアログ。拒否時・位置取得失敗時に案内が出る。
- [ ] 観察地図から属の詳細に移動できる。
- [ ] 写真削除のキャンセル・確定。最後の写真を削除すると写真あり対象から外れる。
- [ ] 位置削除で属と登録写真の位置情報が消える。
- [ ] 機内モードで図鑑、クイズ、成績、登録済み写真が利用できる（地図背景は保証外）。

## バックアップ・庭

- [ ] 写真込みバックアップをアプリ外のファイルへ保存できる。
- [ ] 復元選択→キャンセルで変更なし。確定で成績・写真・位置が戻る。
- [ ] 壊れたJSONや学習データだけのJSONは復元できず、現在の記録を維持する。
- [ ] 庭に開花済みの植物と復習案内が出る。キャラクターは仮表示で、報酬やショップは未実装。
- [ ] 同じBundle IDの次ビルドで上書きし、記録が維持される（次回更新時）。
