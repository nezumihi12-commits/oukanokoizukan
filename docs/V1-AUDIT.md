|予測候補のない入力|再利用・修正|専用フリック/英字パッド。Return は送信しない|

schema 1/2→3。移行前 state.json を state-before-v3.json に原子的に複製してから保存する。未知の将来スキーマ・破損ファイルは空データで上書きしない。写真ディレクトリと bundle identifier は変更しない。
既存の各回答には用途や時刻が十分にないため、過去の正式復習/演習別正答率を正確に復元することはできない。旧総合成績・セッションは保持し、新規回答から分離する。

技術スパイク: SwiftUI + SpriteKit、15植物と背景クラスター、5頭身の仮人型、限定カメラ、タップ判定を独立シーンとして検証する。Windows 上では iOS フレームレート・IME/触覚を実測できないため、実機合格と混同しない。専用入力パッドは OS IME を起動しない設計。

仕様内の暫定競合: 鑑賞ズームは詳細な第4章の限定ズームを採用（第29章は将来検討）。不正解60日段階の平均は (30+14)/2=22日、120日段階は45日。短い文字列の惜しい判定は切り捨て20%（5文字未満は完全一致のみ）。
