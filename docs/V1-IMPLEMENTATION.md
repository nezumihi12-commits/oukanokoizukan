## 実装済みの主要ロジック

- 新規学習だけが必須3形式の初回クリアを進める。予習/スキップ/再確認を接続。
- 演習は初回クリア・開花・復習段階・期限を動かさない。用途別正答率と各確定回答を保存。
- 正式復習は1属1形式。古い形式別復習日時を優先し、同日時では正答率と安定した順序で選ぶ。
- 期限順で最大5属、開始前に非答え情報だけプレビュー。「幽香に訊く」で候補から外して補充。近日予告と自由復習、追加セット導線。
- 間隔1/3/7/14/30/60/120日。期限後正解+1、惜しい同じ段階の全間隔、不正解は1段階戻して前2段階の間隔平均。早期正解は残時間10%を段階につき1回。早期不正解は元期限を越えない。
- 保護はmin(24時間,実際の予定間隔/3)。明示的答え確認だけ属単位24時間ロック。図鑑の自動閲覧記録は廃止。正式復習の通常フィードバックでロックしない。
- 期限超過からだけ退色。図鑑/演習で退色を巻き戻さない。写真ボーナスは新しく設定した正式復習サイクルへ一度だけ5%。早期で新サイクルを作らない場合は写真ボーナスを付けない。
- 所属/表示/配置権限を分離。枠が埋まっても控え。手動配置を勝手に動かさず、解放は安全な節目へ保留。
- 曖昧の庭は似姿のみ。元の植栽を動かさず、解放後は空でも残る。

## 画面と技術選定

SwiftUIは図鑑/学習/設定、SpriteKitは庭の座標・植物・人物・z順・微揺れ。
固定ホーム、鑑賞専用入力、観察から同じカメラで編集、トレイ選択/ドラッグ投入/長押し移動/入替/破棄/Undoを接続。
直接描画を原則15植物へ限定し、背景は少数クラスター。設定にFPSを表示する実機スパイク画面を用意。
専用カタカナ/英字パッドはOS IMEを開かない。Returnは送信せず、欄移動か閉じる。惜しいは編集距離20%の切り捨てで、5文字未満は完全一致のみ。
写真は永続JPEGファイル+JSONメタデータ、バックアップには実バイトをBase64で含める。外観差分は307属分の受け口と選択UIを実装し、未制作の候補は空にしている。架空の花色等は追加していない。
通知は任意許可、1日1回、計算できる次の1件のみ予約。利用時に更新し、放置時に毎日催促し続けない。アニメーション/触覚設定、元コミット表示、仮の花アイコンを追加。
署名用の内部名はASCII、日本語アイコン下表示はja.lprojで指定。SideStoreのappIdNameエラー再発有無は実機項目。
